## 3. 核心页面详细设计

### 3.1 工作台 `/dashboard`

**区域划分**

| 区域 | 内容 |
|---|---|
| 顶部指标卡（6 张） | 今日新增会员、今日活跃会员、今日消费额、今日充值额、储值负债（本金）、积分负债；每张卡含环比箭头 |
| 待办卡片 | 待审批退单（数）、待处理导入任务、发送失败消息、对账差异（红点告警） |
| 图表区 | ① 会员增长趋势（折线，近 30 天，新增/活跃双线）② 消费与充值双轴柱线图 ③ 支付方式占比环形图 ④ 等级分布漏斗/柱状 |
| 快捷入口 | 收银台、开卡充值、发券、会员建档（大按钮，指向高频操作） |
| 榜单 | 今日门店排行 Top5 / 员工业绩 Top5 |

**组件复用**：`StatCard`、`ChartCard`、`TodoList`、`RankList`

### 3.2 会员列表 `/member/list`（最高频页面）

**筛选区（可折叠，支持保存为「我的筛选」）**

```
关键词[会员号/手机号/姓名/昵称] | 手机号 | 等级▾ | 标签▾(多选) | 状态▾ | 来源▾ | 门店▾
余额区间[min-max] | 积分区间 | 入会时间[日期范围] | 最近消费时间 | 生日月份▾ | 是否沉睡☑
[查询] [重置] [高级筛选 ▾]                              已选条件标签化展示
```

**操作区**：新增会员、批量导入、导出（异步任务）、批量打标签、批量发券、批量调整等级

**表格列**

| 列 | 说明 |
|---|---|
| 勾选框 | 批量操作 |
| 会员号 | 可点击进详情，复制按钮 |
| 会员 | 头像 + 昵称 + 姓名（手机号脱敏，hover 显示完整可点击复制） |
| 等级 | 彩色 Tag（等级颜色可配） |
| 标签 | 最多显示 2 个 + `+N` |
| 余额 | 本金（黑）+ 赠送（灰小字），金额右对齐 |
| 积分 | 千分位 |
| 累计消费 / 笔数 | |
| 最近消费 | 相对时间（如"3 天前"）+ 悬浮显示精确时间 |
| 归属门店 | |
| 状态 | Tag |
| 操作 | 详情 / 收银 / 充值 / 发券 / 调整 / 更多▾（改等级、冻结、备注、注销） |

**交互细节**
- 行内快捷充值/发券 → 弹窗操作，成功后就地刷新该行数据（不整页刷新）
- 表格虚拟滚动（超 1 万行）或严格分页；排序字段白名单
- 每一行操作按钮受权限码控制（无权限则不渲染）
- 点击行 → 右侧抽屉展示「会员 360° 速览」（不跳页），抽屉可「展开完整页」

### 3.3 会员 360° 详情 `/member/detail/:id`

**顶部信息条**：头像、昵称/姓名、会员号、等级 Tag、手机号（脱敏 + 查看完整需权限）、归属门店、入会时间、状态；右侧操作按钮：收银、充值、发券、调整、改等级、冻结、合并、打印会员卡

**资产卡片区（4 张）**：本金余额、赠送余额、积分（含即将过期提示）、成长值（含距下一等级进度条）

**页签内容**

| 页签 | 内容 |
|---|---|
| 资产总览 | 资产卡 + 收支趋势小图（近 6 个月）+ 余额构成饼图（本金/赠送） |
| 余额流水 | 时间筛选 + 类型筛选，表格：时间/类型/变动/变动后/关联单号/门店/操作人/备注 |
| 积分明细 | 同上 + 到期时间列 + 批次视图切换 |
| 成长值与等级 | 成长值流水 + 等级变更轨迹（时间轴） |
| 消费订单 | 订单表格，可展开看明细，支持退单入口 |
| 卡券 | 券包（状态分组：可用/已用/过期）+ 次卡（剩余次数进度条） |
| 标签与备注 | 标签编辑 + 备注时间轴（可追加） |
| 动线时间轴 | 全部事件按时间倒序混合展示（注册/充值/消费/核销/升级/领券） |

### 3.4 收银台 `/cashier`（核心，Pad 适配）

**布局（三区）**

```

└───────────────┴──────────────────────────┴───────────────────┘
```

**关键交互**

| 场景 | 交互 |
|---|---|
| 识别会员 | 输入手机号后 4 位 → 实时联想下拉（最多 10 条，含等级/余额）→ 选中后右侧结算区显示会员信息 |
| 无会员消费 | 支持"散客"模式：不选会员，直接收银（不计积分/成长值，也可配置是否允许） |
| 扫码识别 | 扫码枪输入：会员动态码 / 静态码 / 券码 / 次卡号，自动路由到对应动作 |
| 选商品 | 点击卡片加入购物车；支持条码枪扫码加入；支持"自由金额"（服务类临时定价） |
| 选券 | 弹窗列出该会员可用券（默认选最优），不可用券置灰并显示原因 |
| 积分抵扣 | 输入框 + "最大可用"按钮；实时联动应收 |
| 支付 | 单选/组合；余额支付显示"本金/赠送"扣减明细；现金输入实收自动算找零 |
| 结算 | 幂等键生成 → 调接口 → 成功弹出小票预览 + [打印] [再来一单] |
| 挂单/取单 | 挂单最多保留 24 小时，取单恢复购物车与会员 |
| 交班 | 弹窗显示本班次汇总（同接口 §5.6）→ 确认交班生成交班单 → 可打印 |
| 快捷键 | F2 会员搜索、F4 商品搜索、F8 结算、F9 挂单、F12 交班（Pad 可配） |

**异常处理**：网络失败保留购物车不清空；余额不足给出"余额不足，还差 X 元"；重复提交由幂等键兜底返回首次结果并提示"该单已结算"。

### 3.5 发券向导 `/marketing/grant`

| 步骤 | 内容 |
|---|---|
| ① 选择券 | 券模板列表（可多选，设置每张发放数量） |
| ② 选择人群 | 三种模式：**指定会员**（粘贴手机号/会员号 或 从会员列表勾选）、**按条件筛选**（等级/标签/消费区间/最近消费/生日月，实时预估人数）、**全部会员**（二次确认 + 输入确认文本） |
| ③ 确认发放 | 展示预估人数、券成本估算、是否发订阅消息 → 提交 → 生成任务号 → 进度条 + 结果统计（成功/失败/跳过原因） |

### 3.6 券模板编辑 `/marketing/coupon-tpl/edit`

**左侧表单**：基本信息（名称/类型/面额或折扣/最低消费/封顶）、有效期（绝对区间 or 领取后 N 天）、适用范围（门店多选/商品多选/排除商品）、限领与总量、叠加规则（是否可叠加 + 互斥组）、自助领取开关、使用说明文案
**右侧实时预览**：券样式卡片（正面：券名/面额/门槛/有效期；按小程序样式渲染，所见即所得）

### 3.7 等级设置 `/level/list` + `/level/rule/:id`

- **等级列表**：卡片式横向排列（普通→银→金→铂→钻石），每卡显示折扣率、积分倍率、生日礼、升级积分；顶部有「权益对比表」切换视图
- **规则编辑**：可视化条件构造器
  ```
  升级条件  [全部满足 ▾]
   ├ 累计成长值    [>= ▾] [3000     ]
   ├ 近12月消费额  [>= ▾] [1500     ]
   [+ 添加条件]
  保级条件  [近12月消费额 >= 1200]
  等级有效期 [12] 个月（0 = 永久）
  ```
- 保存前提供「**模拟测算**」：输入一个成员样本或选择现有会员，预览是否符合新规则（避免规则错误导致批量升级）

### 3.8 对账中心 `/account/reconcile`

- 顶部：最近一次对账时间、差异条数（0 为绿，>0 为红并告警）
- 差异清单表格：会员、账户类型（本金/赠送/积分）、账户余额、流水合计、差异额、最近变动时间、处理状态
- 操作：查看该会员流水、生成调账单（写调整流水，原因自动生成）、导出差异清单

### 3.9 报表页通用结构

`筛选条件区（日期范围/门店/维度）→ 指标卡 → 图表 → 明细表格 → 导出按钮`
统一使用 `ReportPage` 高阶组件封装，减少重复代码。

**关键交互与容错**

| 场景 | 处理 |
|---|---|
| 点击支付 | ① 创建充值单（幂等键）→ ② `prepay` 统一下单 → ③ `wx.requestPayment` → ④ 进入结果页轮询 |
| 用户取消支付 | `wx.requestPayment` 的 `fail`（`cancel`）→ 关单或提示"订单已保留 15 分钟，可在待支付中继续" |
| 支付成功但页面未收到回调 | 结果页退避轮询（1.5/3/5/8/10 秒，最多 6 次）；仍未知则提示"到账确认中"，服务端掉单补偿兜底 |
| 网络异常 | 保留订单号，进入"待支付订单"页可继续支付；**不重复创建订单**（幂等键复用同一订单） |
| 未绑定手机号 | 支付前拦截并引导绑定（`70012`） |
| 支付功能未开启 | `pay.enabled=false` 时隐藏在线充值入口，改为"到店充值"说明页（扫码/现金） |
| 重复点击 | 按钮 loading + 幂等键，服务端 `70006` 时提示"该充值单已支付"并直接跳结果页 |
| 申诉入口 | 结果页底部"支付遇到问题？"→ 客服会话，附支付单号便于排查 |

**入账后展示**：结果页展示"余额 +500 / 赠送 +50 / 积分 +200 / 券 ×1"的到账明细，并提示开启订阅消息接收通知。
